# Static Assets Directory

This small SVG set supports navigation and data scanning; it does not replace interface text or API-backed content.

- `brand/` contains the platform's abstract skill-intelligence mark and the compact gold Lion Capital treatment used in the header.
- `icons/` contains the shared, 1.8px technical line-icon family for district, metrics, industry, action, and assistant contexts.

All marks are local, scalable SVGs with no external asset requests.
