2. COVERAGE AND EXTRACTION SCOPE
--------------------------------------------------------------------------------
Coverage includes full 4-year undergraduate B.Tech Computer Science and Engineering:
- Basic Sciences (BSC): Physics, Linear Algebra, Probability & Statistics, Biology.
- Engineering Sciences (ESC): Digital Logic Design, Basic Electronics, Basic Electrical Engineering, Engineering Drawing.
- Program Core Courses (PCC): Data Structures & Algorithms, Discrete Structures, Microprocessors,
  Computer Organization, Theory of Computation, Operating Systems, Database Management Systems,
  Computer Networks, Software Engineering, Compiler Construction, Cryptography & Network Security,
  Design & Analysis of Algorithms, Artificial Intelligence.
- Program Elective Courses (PEC): Cloud Computing, Machine Learning, Deep Learning, Big Data Analytics,
  Computer Vision, Natural Language Processing, GPU Computing, Blockchain, IoT, System Administration,
  Advanced System Programming, Parallel Architecture, Distributed Systems, Web Technologies.
- Multidisciplinary Minors (MDM): AI/ML Mastery, Large Language Models, Generative AI, Quantum Computing.
